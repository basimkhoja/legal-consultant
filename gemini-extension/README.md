# legal-consultant Gemini CLI extension

> Generated by `scripts/build-runtimes.py`; do not edit.

Install from a local checkout: `gemini extensions install /path/to/legal-consultant/gemini-extension` (or `gemini extensions link /path/to/legal-consultant/gemini-extension` while developing).
Install from GitHub: `gemini extensions install https://github.com/basimkhoja/legal-consultant` (the extension folder is `gemini-extension/`; if the CLI requires the manifest at the repository root, install from the local folder instead).

Commands are `/commercial-legal:<skill>`, `/corporate-legal:<skill>`, `/employment-legal:<skill>`; skills are also selectable by description. Guardrails are in `GEMINI.md`.
