## Runtime findings (fixed in this task)

These are Codex-runtime facts, reproduced with probe commands inside `codex exec` (see `tests/results/raw/EMP-01-codex-readonly.*` and `EMP-01-codex-tls.*`).

1. **The `read-only` sandbox has no network.** `CODEX_SANDBOX_NETWORK_DISABLED=1` is set; `scripts/fetch-law.py`, any `curl` inside a pipeline or subshell, and `curl` launched from Python all fail with `curl: (6) Could not resolve host: laws.boe.gov.sa`. A bare top-level `curl <url>` does get through (Codex appears to run it outside the sandbox as a known read-only command), which is why the first attempt's `curl -I` probe returned portal headers while the script failed. The tracker's suggested `-s read-only` invocation therefore turns every research step into a stopped run: the skill did exactly what Step 0(5) prescribes (reviewer note with `portal fetched: no`, every number PENDING, the three options, nothing tagged `[BOE — Arabic]`), which is the EMP-04 behaviour, not the EMP-01 deliverable.
2. **With network enabled, the sandbox blocks the macOS Keychain.** `laws.boe.gov.sa` serves its leaf certificate without the DigiCert intermediate; macOS `curl` normally completes the chain from the system trust store, but inside the seatbelt sandbox verification fails with `curl: (60) SSL certificate problem: unable to get local issuer certificate`. Second attempt: stopped run again, for this reason.
3. **The portal redirects HEAD requests into a loop.** `curl -I <law URL>` follows 50 redirects to `/Error?code=404` and fails; a GET returns 200. Codex chose `-I` for its probe.

**Fixes made (committed with T2).**

- `scripts/fetch-law.py`: when the default `curl` exits 60, retry once with `--cacert scripts/certs/boe-chain.pem`. The chain file holds only the public DigiCert Global G2 TLS RSA SHA256 2020 CA1 intermediate (downloaded from cacerts.digicert.com) and the DigiCert Global Root G2 (copied from `/etc/ssl/cert.pem`); nothing private is pinned, and the fallback is never used when the default verification succeeds. Tested inside the sandbox: HTTP 200, and the third EMP-01 attempt fetched the Labor Law and quoted Arts. 76, 77 and 80 with `[BOE — Arabic]`.
- `scripts/build-runtimes.py`: the Codex `AGENTS.md` gained a "Sandbox and network (Codex)" runtime rule stating the invocation above, the Keychain fallback, and "probe with GET, never `curl -I`". Regenerated; `--check` passes; only `AGENTS.md` changed among the generated files.
- `docs/runtime-matrix.md`: the primary-source fetch row records the Codex invocation and the fallback.

No skill text (`skills/*/SKILL.md`, `JURISDICTION-STEP.md`) needed to change for EMP-01.
