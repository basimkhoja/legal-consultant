## Runtime findings (recorded in `docs/runtime-matrix.md` and `README-LEGAL-CONSULTANT.md`)

1. **Auth.** The free "Gemini Code Assist for individuals" OAuth tier (`tierId: free-tier`) is rejected by the CLI with `IneligibleTierError`. Reproduced with a one-word prompt outside the repository, on 0.58.0 and on `npx @google/gemini-cli@preview` (0.59.0-preview.0), so it is not caused by the extension, the repository, or the CLI version. Not fixable from this session: it needs either a `GEMINI_API_KEY` (AI Studio), Vertex AI (`GOOGLE_GENAI_USE_VERTEXAI=true`, `GOOGLE_CLOUD_PROJECT`, `GOOGLE_CLOUD_LOCATION`, with ADC), or a paid Code Assist licence on the Google account. Nothing under `~/.gemini` was read or changed beyond the extension link.
2. **`--consent`.** Required for scripted `gemini extensions link` / `install`.
3. **Skill conflict warnings.** From a clone, Gemini discovers `.agents/skills/` (the Codex adapter) as workspace skills and prints `Skill conflict detected: "<plugin>-<skill>" from …/.agents/skills/… is overriding the same skill from …/gemini-extension/skills/…` once per skill (40 lines). Both copies are generated from the same canonical `SKILL.md` by `scripts/build-runtimes.py`, so the override is content-neutral. Warning only; it does not occur when the extension is used outside the repository. Nothing to change in the generator; recorded in the matrix's known limitations.
4. **Trusted folder.** In an untrusted directory, headless `gemini -p` prints `Approval mode overridden to "default" because the current folder is not trusted` and then refuses to run; `--skip-trust` or `GEMINI_CLI_TRUST_WORKSPACE=true` is the headless route. The repository root became trusted when the extension was linked; the scratch folder used for the trivial-prompt repro was not.
5. **GitHub install form.** Not tested: the `multi-jurisdiction` branch is not pushed (task T5), so `gemini extensions install https://github.com/basimkhoja/legal-consultant` would fail for that reason, not because of the sub-folder manifest. Still open in `docs/runtime-matrix.md`.
